Sem dejte fotky realizací / Покладіть сюди фото реалізацій.

- Формати: jpg, png, webp. Рекомендовано: ширина до 1600 px, вага до 400 КБ (інакше сайт буде повільним).
- Підпапки = категорії (фільтри): byty, domy, koupelny, kancelare. Назви латиницею, без пробілів.
- Назва файлу = підпис у перегляді: "01-obyvaci-pokoj.jpg" -> "obyvaci pokoj".
- Порядок: за назвою файлу (тому можна нумерувати 01, 02, 03...).
Після додавання фото запустіть "npm run build" знову.
